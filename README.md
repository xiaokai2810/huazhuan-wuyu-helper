# 花砖物语：人机对战与对局助手

线上地址：[GitHub Pages](https://xiaokai2810.github.io/huazhuan-wuyu-helper/)。

双击 [花砖物语助手.html](花砖物语助手.html) 即可在浏览器里使用。它是单文件，离线可用。

## 花砖视觉

参照用户提供的小程序对局截图，五种砖分别绘制旋涡、金色缠花、红色花环、暗色交织线与青色星花纹样。手机端采用蓝色桌面，上方对手、下方自己；中间圆盘按 2–1–2 排列，右侧为公共牌堆和已选砖块。双方棋盘底部展示地板扣分格、总分和本轮净变化；完整花纹也用于手动助手。矢量素材内嵌在 `tile-art.js` 中，随砖格清晰缩放，离线版不依赖外部图片。

## 双人满墙竞速

大厅选择“双人满墙竞速”。当前为同一手机两人轮流操作，双方每手使用相同的 90 秒 / 60 秒限时。目标是先完成整面 25 格花砖墙，完成一横行后仍继续，不限轮次；最后所需图案线完成时立即贴墙判胜，不必等本轮公共池取完。积分保留作记录，不决定竞速胜负。对局会保存在当前浏览器中，可返回大厅再继续。

## 人机对战

打开页面默认进入大厅（`#play`），选择等级、每步限时（90 秒 / 60 秒）与先手后点击“开始对局”，自动进入独立桌面（`#match`）。点击圆盘或中央区的一种颜色，选择自己的一条高亮图案线，查看成墙收益、溢出和地板扣分预览，再确认落砖。支持取消选择、手机一屏查看双方棋盘与公共池、规则与记录抽屉、结算弹窗及回大厅续局。原对局助手仍在 `#helper`。

完整支持发牌、地板扣分、跨轮保留、牌袋回收、先手交接及终局奖励；每轮结算后点击下一轮。每次出手重置倒计时，返回大厅暂停；刷新后按原截止时间继续，不会刷新限时。超时优先执行已选合法落点，否则由本地算法代走一步。对局自动保存在本机浏览器，刷新后可以继续。

三个等级使用相同规则：

- 入门：多数出手带有随机性，适合熟悉规则。
- 进阶：按当前局面评估相邻得分、图案线完成率、终局目标与地板风险。
- 宗师：本页最高配置。采用数字压缩局面、迭代加深、主变例搜索、Alpha-Beta 剪枝、局面缓存及晚着缩减，早期最多保留 24 个高价值后续分支；剩余颜色组不超过 8 组时在时间预算内尝试完整搜索。本轮终局会精确考虑奖励和完整横行破同分。默认每手预算约 7.8 秒，通过 Web Worker 计算，不保证全局最优。

所有等级均为本地算法，不接入任何 AI 服务。双方总分在一轮公共砖取空后统一结算，顶部实时显示本轮待结算净分，结算面板列出双方的前后总分、贴墙得分与地板扣分；未满图案线保留且不立即得分。

人机计算只收到公开棋盘，无法读取未来牌袋顺序。难度在开始新局时生效。页面顶部可随时切换回“对局助手”，两个模式的数据分别保存。

## 快速录入

1. 选中一种颜色（键盘 `1`–`5`），点击每个工厂的砖格。按 `0` 选橡皮，或右键砖格清空。
2. 用中央区的 `+`、`−` 填入各颜色数量，勾选先手标记是否还在。
3. 选中颜色，点击自己图案线上的第 N 格，表示这行已有 N 块该色砖；点击墙格标记已经贴好的砖。
4. 如需估计对手下一手，勾选“录入一位对手”并录入其棋盘。多人局建议录入最可能影响你的一位。
5. 右边实时显示推荐拿砖、落点、本轮成墙得分和新增地板扣分。

“填入示例”可以先体验操作。局面会尽可能保存在当前浏览器的本地存储里。

## 计算范围

- 使用原版 Azul 彩色墙的工厂取砖、中央区、先手标记、图案线、贴墙得分和地板扣分规则。
- 枚举当前所有合法拿砖与落点，按本轮得分、未完成图案线的价值和可选的对手下一手排序。
- 这是局面启发式建议，不保证最优；它不会读取微信画面或自动点击小程序。
- 小程序如启用了灰墙等变体，当前版本的建议不适用。

规则参考：[Next Move Games 官方 Azul 说明书](https://cdn.svc.asmodee.net/production-nextmove/uploads/sites/4/2024/06/EN-Azul-Rules-Next-Move-web.pdf)。

开发校验：在此目录执行 `npm test`。`node ai-benchmark.js` 用固定种子、轮换先手，以相同的思考预算比较新宗师与上一版大师；可通过 `AI_MS=500` 调整测试预算。修改源文件后执行 `python3 build_standalone.py`，同时更新单文件版与独立 Worker。
